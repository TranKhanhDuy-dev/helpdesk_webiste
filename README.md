# IT Helpdesk Ticketing System

An IT Helpdesk Ticketing System designed to manage IT support requests through a ticket-based workflow.

The system allows users to create and track support tickets, communicate with support staff, upload attachments, and rate support services. It also provides ticket assignment, user management, notifications, and dashboards for monitoring ticket statistics and staff performance.
